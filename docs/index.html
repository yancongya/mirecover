使用流程
找回照片，只要三步

就算不太会用手机，跟着这三步也能顺利找回照片。

1

📁 准备缓存目录

用手机「文件管理」，把相册缓存里的 full_size 文件夹复制到 Download 目录。

2

🔧 一键修复

在「主面板」确认路径，点橙色「修复文件」，自动把 `.0` 变成 `.jpg`。

3

🖼️ 导出相册

在「修复预览」勾选想要的图片，点「导出选中到相册」就完成了。
